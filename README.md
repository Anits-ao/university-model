# University Model

A Java project modeling a college, academic departments, courses, faculty, students, and revenue.

## Departments

- Information Systems
- Data Architecture
- Software Engineering

## How to Run

Compile the Java files:

    mkdir -p out
    javac -d out $(find src -name "*.java")

Run the main program:

    java -cp out UniversityExample

## Example Output

    Information Systems Revenue: 180000
    Data Architecture Revenue: 180000
    Software Engineering Revenue: 180000
    College Total Revenue: 540000
